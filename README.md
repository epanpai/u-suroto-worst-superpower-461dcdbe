## The entry

The power is not weak — it is already spent. A hero who burned their one miracle in 2009, probably on something dumb, and has been ordinary ever since.

## How it works

`main.ts` (Node 22, stdlib only) writes the fixed one-liner to `/output/entry.txt` — 98 characters, inside the 1–140 character gate. Deterministic, no network, no secrets, no randomness.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
